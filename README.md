## USDT 付款到底怎么走

支持 USDT 的商家分两种结算模型，付款前先搞清楚你面对的是哪一种，后面很多问题都由此而来。

**第一种是充值余额。** USDT 先充进账户，系统按当时汇率换成账户余额（欧元或人民币），再用余额下单和续费。好处是提前充好余量，到期不用每次折腾转账；代价是充值时有汇率换算，零头会差几毛，且余额模型的商家通常设最低充值门槛。CheapServ 就是这类，最低充值 **$25**，余额不过期、未用可退；LisaHost 也是先换成人民币余额。

**第二种是按账单支付。** 下单时系统按订单金额生成一笔加密货币账单，金额锁定一段时间，链上确认后自动开通。Infrawire 是这种，账单支付链接有效期 12 小时，付款不足可以在有效期内再补一笔。续费不会从钱包自动扣款，每次到期前单独开一张账单。

流程本身五步，两家模型都适用：

1. 选网络。TRC-20 和 ERC-20 是两个不同链上的地址，不通用。
2. 生成专属地址或账单。页面上显示哪个网络的地址，就只能往那个网络发。
3. 从钱包或交易所按页面金额转账。**金额必须与页面显示完全一致**，多一分少一分都可能无法自动识别，要走人工核账。
4. 等链上确认。确认数达标后系统标记已支付。
5. 余额到账或账单生效，服务器自动开通。

链上手续费始终由你的钱包承担，商家端可能收 0 手续费。0 手续费说的是商家不加价，不是你转账不花钱。

## 哪一步最容易亏钱

**网络选错，钱找不回来。** 这是唯一会造成实际损失的步骤，也是最容易犯的。TRC-20 地址和 ERC-20 地址在不同链上，把 USDT 发到不匹配的网络，商家和你都取不出来。CheapServ 的 FAQ 写得很直接：发错网络无法找回。下单页面显示的是哪条链，就只走哪条链，不要在钱包里凭印象选。

**小额走 ERC-20 不划算。** 以太坊 gas 波动大，几美元的订单配上几美元的 gas，等于多付一倍。TRC-20 在小额场景下更合适，交易所提币手续费通常也更低。如果你的 USDT 本来就在以太坊上，先算一下 gas 再决定要不要跨链。

**余额模型的汇率零头。** USDT 换成欧元或人民币余额时按当时汇率结算，实际到账金额和充值金额会差一点。金额还要求与系统生成的数字完全一致，差一点就要找客服手工核账，耽误开通时间。

**最低充值门槛让“先充 5 U 试试”失效。** 有门槛的商家，试错成本直接抬到门槛金额。CheapServ 的 $25 意味着你不能拿几美元验证流程。AvaHost 的最低充值金额公开页面没有写，第一次付款前最好在账单页确认，或者先用最低档套餐走一遍完整流程。

**金额和链接都有时效。** CheapServ 的充值金额锁定 30 分钟，Infrawire 的支付链接 12 小时有效。超时后汇率或金额重算，按旧页面转过去的钱可能对不上。
